# 😊 Image Mood Detector

AI-powered facial emotion detection application built with Streamlit and Hugging Face Transformers.

## Overview

This project detects emotions from uploaded face images using a pre-trained deep learning model. The application analyzes facial expressions and predicts the most likely emotion along with a confidence score.

## Features

✅ Upload face images
✅ Detect emotions automatically
✅ Display confidence score
✅ Interactive and clean Streamlit UI
✅ Fast predictions using Transformer models

## Technologies Used

* Python
* Streamlit
* Hugging Face Transformers
* PyTorch
* Torchvision
* Pillow

## Installation

Clone the repository:

```bash
git clone https://github.com/ShahFaisal45/image-mood-detector.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
